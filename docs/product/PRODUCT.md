# COSY Studio

Blueprint-to-App Intelligence Platform.

**Scan. Understand. Rebuild. Ship.**

COSY Studio is the selling product. EEEEEE is not a standalone scanner, the old app-builder MVP is not an isolated generator, and COSY is not a UI mock — they are one workspace.

## Workflow

1. Import public evidence (Blueprint ZIP today, public URL in Milestone 3)
2. Inspect Blueprint, checksum, tokens, WordPress/Elementor signals, limitations
3. Plan architecture and migration risk (Milestone 4)
4. Generate a real app, verify the build, repair on failure (Milestone 5)
5. Review in Canvas (Milestone 6)
6. Export project ZIP / Cursor plan (Milestone 7)

## Face

- Rebuild readiness %
- Gold accent on a dark technical canvas
- Demo project is labeled Demo
- Later milestones show scheduled empty states, not fake success

## In this build

Projects, wizard, ZIP importer, Blueprint workspace, demo ILUMINAT snapshot, persist of import rows.
