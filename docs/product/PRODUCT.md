# COSY Studio

Blueprint-to-App Intelligence Platform.

**Scan. Understand. Rebuild. Ship.**

COSY Studio is the selling product. EEEEEE is not a standalone scanner, the old app-builder MVP is not an isolated generator, and COSY is not a UI mock — they are one workspace.

Repository: [github.com/ENZO7700/cosy-studio](https://github.com/ENZO7700/cosy-studio)

## Offer

Agencies and rebuild teams import **public frontend evidence**, inspect it as a Blueprint, then plan, generate, verify, and export a real application foundation.

The landing kicker is **Blueprint Scanner — Powered by COSY Studio**. The product name is always COSY Studio.

## Workflow

1. **Scan / import** — Blueprint ZIP or public URL / pasted HTML.
2. **Understand** — checksum, tokens, WordPress / Elementor signals, forms, limitations, evidence ledger, architecture, risks, tasks.
3. **Plan** — architecture graph, migration risks, Cursor tasks.
4. **Rebuild** — generated files, workspace verification, repair on failure.
5. **Review** — COSY Canvas generated preview.
6. **Ship** — application ZIP and Cursor plan ZIP.

## Face

- Rebuild readiness %, never clone %
- Dark technical canvas, gold accent `#D8A84B`
- Demo project is labeled **Demo**
- Verification copy is honest: exit 0 from `cosy-verify`, not a cloned WordPress runtime
