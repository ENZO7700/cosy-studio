# COSY Studio

Blueprint-to-App Intelligence Platform.

**Scan. Understand. Rebuild. Ship.**

COSY Studio is the selling product. EEEEEE is not a standalone scanner, the old app-builder MVP is not an isolated generator, and COSY is not a UI mock — they are one workspace.

Repository: [github.com/ENZO7700/cosy-studio](https://github.com/ENZO7700/cosy-studio)

## Offer

Agencies and rebuild teams import **public frontend evidence**, inspect it as a Blueprint, then (in later milestones) plan, generate, verify, and export a real application.

The landing kicker is **Blueprint Scanner — Powered by COSY Studio**. The product name is always COSY Studio.

## Workflow

1. **Scan / import** — Blueprint ZIP today. Public URL in Milestone 3.
2. **Understand** — checksum, tokens, WordPress / Elementor / JetEngine signals, forms, limitations, evidence ledger.
3. **Plan** — architecture graph, migration risks, Cursor tasks (Milestone 4).
4. **Rebuild** — generated files, verified build, repair on failure (Milestone 5).
5. **Review** — COSY Canvas (Milestone 6).
6. **Ship** — application ZIP and Cursor plan ZIP (Milestone 7).

## Face

- Rebuild readiness %, never clone %
- Dark technical canvas, gold accent `#D8A84B`
- Demo project is labeled **Demo**
